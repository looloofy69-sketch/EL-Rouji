# Versioning

EL-Rouji intends to use Semantic Versioning (`MAJOR.MINOR.PATCH`) once the first release is validated.

- `0.x` denotes pre-stable development.
- `1.0.0` should only be tagged after a reproducible build, core-flow QA, security review, and release checklist are complete.
- No release tags are asserted by this document; versions must be created after verification.
